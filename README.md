# 酒店智能会议记录助手

专为酒店行业设计的智能会议记录管理工具，支持会议记录的创建、编辑、预览和导出。

## 功能特性

- 📝 双输入模式：支持手动输入和语音输入
- 🎯 酒店行业专属：内置酒店常见会议类型模板
- 📋 标准格式：严格按照酒店行业标准会议记录格式
- 💾 本地存储：所有数据安全存储在浏览器本地
- 📤 导出功能：支持导出为 Markdown 格式
- 📱 响应式设计：支持桌面和移动设备

## 技术栈

- React 18
- React Router
- Tailwind CSS
- Vite
- Lucide React (图标)

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 使用说明

1. 在首页选择会议类型创建新会议
2. 填写会议基本信息
3. 编辑会议内容和行动项
4. 预览会议记录
5. 导出为 Markdown 文件

## 项目结构

```
src/
├── components/
│   ├── Home.jsx          # 首页组件
│   ├── MeetingEdit.jsx   # 会议编辑组件
│   └── MeetingPreview.jsx # 会议预览组件
├── services/
│   ├── storage.js        # 本地存储服务
│   └── export.js         # 导出服务
├── types/
│   └── index.js          # 常量和类型定义
├── App.jsx               # 主应用组件
├── main.jsx              # 应用入口
└── index.css             # 全局样式
```

## 会议记录格式

系统严格按照以下格式输出会议记录：

- 会议名称、编号、时间、地点
- 主持人、记录人信息
- 参会人员、缺席人员
- 会议议题
- 各部门工作汇报
- 议题讨论与决议
- 行动项清单
- 其他事项
- 签字区域

## 数据存储

所有数据存储在浏览器的 localStorage 中，确保数据安全和隐私。
